Development & Compliance

1. Development Process

This website was planned and developed to help users explore and adopt pets easily. The development process included planning, designing, coding, and testing.

  • Planning: Decided pages like Home, About, Pets, Adopt, Gallery, Contact.
  • Design: Created layout with navbar, cards, and sections.
  • Development: Built using HTML and CSS with separate files.
  • Testing: Checked all links, forms, and images.

5. Privacy Notice

User details collected through the contact and adoption forms are only used for communication and adoption purposes. No data is shared with third parties.

7. Security Awareness

  • No sensitive personal data is collected.
  • Basic input fields are used to avoid misuse.

8. Censorship & Content Appropriateness

Content on this website is carefully selected to be appropriate for all users. No harmful, offensive, or misleading content is included. This ensures the website is safe and suitable for a general audience.
